# Glossary

Canonical language for this site. Code and copy follow these terms.

## Identity

- **霜花** — the display name. Used wherever the name is *shown*: hero title, logo, footer, page titles.
- **Shimoka** — the romanization of 霜花. Used in SEO titles and prose so people who heard the name can search it. Never used as a handle.
- **kyuna0312** — the handle. Used for every account link (GitHub, Twitter, Instagram) and handle-styled text (logo subtext, footer byline, hero caption).
- **Frost flower** — the literal meaning of 霜花; the site's founding metaphor.

## Positioning

- **Primary**: Systems & Developer Tooling Engineer — developer environments, editors, low-level experiments (Rust, C/C++, Lua, Linux, terminal tooling). Source: the owner's own GitHub portfolio audit (Aug 2026).
- **Secondary**: web/full-stack product work (TypeScript, React, Next.js) — shown, never leading.
- Project descriptions never use "toy" or "test"; they name what was implemented and what was explored.

## Design language ("Magia paper")

Derived from the owner's own Magia project (kyuna0312/madoka), 魔法少女まどか☆マギカ CSS studies.

- **paper / pane** — page ground and raised surface (light mode: warm paper; dark mode: Homura night violet).
- **ink** — headings and the stage frame.
- **rime** — body text (cold gray, from "rime frost").
- **ice** — Sayaka-blue accent: structure, links, the 霜 kanji.
- **bloom** — Madoka-pink/red accent: the single warm moment per view, the 花 kanji.
- **gold** — Mami-yellow accent: third voice, used sparingly.
- **Soul-gem rule** — one accent color leads per section; accents are never sprayed.
- **Stage frame** — the thin ink viewport border with dashed arcs, from Magia's title screen.
